# Code of Conduct

OpenCPR adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.

In short: be welcoming and respectful, assume good intent, and focus on what is best for the project and the people who use it. Harassment, personal attacks and discriminatory language are not accepted in issues, pull requests or any other project space.

## Reporting

Report unacceptable behavior to support@opencpr.org. Reports are handled privately by the maintainers, who will respond, investigate and decide on any action as described in the Contributor Covenant's enforcement guidelines.
