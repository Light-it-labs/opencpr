# OpenCPR kiosk (frontend)

The kiosk app of the OpenCPR training booth. It runs fullscreen in Chrome on the booth's touchscreen, reads compressions from the Arduino sensor over Web Serial, and saves each run to the backend API.

Built with React 19, Vite, TanStack Router, TanStack Query, React Hook Form + Zod, Zustand and Tailwind CSS 4.

## Screens

| Route | What it does |
| --- | --- |
| `/setup` | Pick the location and the mode (Arduino or manual). In Arduino mode it asks Chrome for the serial port, or reuses one granted on an earlier run |
| `/` | Attract screen: the start button. Sends you to `/setup` when no serial port is available in Arduino mode |
| `/register` | Shows a QR code; the participant registers on their phone and the kiosk moves on by itself |
| `/r/$sessionId` | The phone-side registration form the QR code opens |
| `/challenge/instructions` | Step-by-step positioning and technique instructions |
| `/challenge/start` | The timed run: countdown, depth bar, 110 bpm metronome, live compressions |
| `/challenge/results` | Score and metrics for the run just finished |
| `/maintenance` | Shown while the booth's firmware is flashed. Keeps the serial port closed and tells the backend to hold its alerts |
| `/terms` | Terms and conditions |

The booth scripts that install the booth computer and start the kiosk fullscreen at boot live in [`scripts/booth/`](../scripts/booth) at the repository root (Ubuntu and macOS), together with the one-time booth setup.

## Local setup

```sh
nvm use                 # Node version from .nvmrc
corepack enable         # pnpm version from package.json
pnpm install
cp .env.example .env
pnpm dev
```

Environment variables (see `.env.example`):

| Variable | Purpose |
| --- | --- |
| `VITE_APP_ENV` | `local`, `development`, `staging` or `production` |
| `VITE_PUBLIC_URL` | This app's own URL, used to build the registration QR code. Phones scan it, so in production it must be the public HTTPS origin |
| `VITE_API_URL` | Backend API base URL. `.env.example` points at a local backend |
| `VITE_SENTRY_DSN` | Sentry DSN (optional) |
| `VITE_SENTRY_TRACE_PROPAGATION_TARGET_REGEX` | Which API URLs get Sentry trace headers (optional) |
| `SENTRY_AUTH_TOKEN`, `SENTRY_ORG`, `SENTRY_PROJECT` | Build-time only, for uploading source maps (optional). Not exposed to the browser |
| `VITE_ENABLE_REACT_SCAN` | Enables React Scan when `VITE_APP_ENV` is `local` (optional) |

Web Serial works in Chrome and Edge only. Without the sensor, pick manual mode on `/setup`: the spacebar simulates compressions.

The 110 bpm metronome in `src/assets/audio/metronome.mp3` is generated by `scripts/generate-metronome.sh` (needs ffmpeg).

## Hosting

This is a single-page app: the web server must serve `index.html` for any path that is not a file, or opening `/setup` directly returns 404. With nginx:

```nginx
location / {
    try_files $uri $uri/ /index.html;
}
```

The kiosk polls `dist/version.json`, written at build time, and reloads itself from the attract screen when a new build lands, so a sealed booth picks up a deploy without anyone reaching the machine.
